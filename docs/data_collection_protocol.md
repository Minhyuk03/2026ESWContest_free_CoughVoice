# Cough-ID 기침 샘플 수집 프로토콜

작성일: 2026-08-05
대상: 화자 3~4명 / 수음 거리 1~2m / I2S MEMS 마이크 1개 (RPi5, hw:2)

---

## 0. 가장 중요한 원칙

**등록(enrollment)용과 검증(test)용 녹음은 반드시 다른 날에 하세요.**

한 자리에서 몰아 녹음한 뒤 그 안에서 학습/검증을 나누면, 모델이 화자의 목소리가 아니라 **그날의 마이크 위치·방 울림·옷 스치는 소리를 외웁니다.** 이 상태로 측정한 정확도는 실제 성능보다 크게 부풀려지고, 데모 당일 완전히 무너집니다.

화자 식별 프로젝트에서 가장 흔하고 치명적인 실수이므로, 일정이 빠듯해도 이것만은 지키세요. 최소 **2개 세션, 서로 다른 날**입니다.

---

## 1. 화자 설계

| 구분 | ID | 인원 | 역할 |
|---|---|---|---|
| 팀원 | `s01`~`s04` | 3~4명 | 등록 + 검증 대상 |
| 외부인 | `x01`~`x02` | 1~2명 | **unknown 판정 검증용.** 등록하지 않음 |
| 네거티브 | `neg` | - | 기침이 아닌 소리. 오탐 억제용 |

외부인 샘플이 없으면 "등록되지 않은 사람을 unknown으로 거르는" 기능을 검증할 방법이 없습니다. 지금 시스템이 항상 `unknown`을 반환하는 스텁이니, 이 부분이 제대로 도는지 확인하려면 반드시 필요합니다.

---

## 2. 세션 설계

| 세션 | 시점 | 용도 | 비고 |
|---|---|---|---|
| `ses01` | 1일차 | 등록(enrollment) | 마이크 위치 고정 |
| `ses02` | 최소 1일 뒤 | 검증(test) | **마이크 위치를 일부러 조금 바꿀 것** |
| `ses03` | 여유 있으면 | 추가 검증 | 다른 방에서 |

세션 2에서 마이크 위치를 살짝 옮기는 건 의도적입니다. 실제 환경 변화에 견디는지를 보기 위한 것입니다.

---

## 3. 녹음 환경

- **거리**: 100cm, 200cm 두 지점. 바닥에 테이프로 표시해두면 세션 간 재현이 쉽습니다
- **방향**: 마이크 정면. MEMS 음향 홀이 화자를 향하게
- **높이**: 앉은 자세 입 높이 (약 110~120cm)
- **환경음**: 에어컨·선풍기는 끄되, 완전 무음실은 피하세요. 실제 사용 환경과 너무 다르면 일반화가 안 됩니다
- **기록**: 세션마다 날짜·장소·마이크 위치·주변 소음 상태를 메모로 남기세요

---

## 4. 수집 항목과 횟수

### 화자별 (팀원 1명 기준)

| 종류 | `--type` | 거리 100cm | 거리 200cm | 설명 |
|---|---|---|---|---|
| 마른기침 | `dry` | 20회 | 10회 | 의도적으로 내는 기침 |
| 자연기침 | `natural` | 10회 | 5회 | 최대한 자연스럽게 |
| 헛기침 | `throat` | 10회 | 5회 | 목 가다듬기 |

**세션당 화자 1명 = 60개**, 2세션이면 **120개**. 4명이면 총 480개입니다.

### 네거티브 (전체 공통, 세션당 1세트)

| 종류 | `--type` | 횟수 | 설명 |
|---|---|---|---|
| 말소리 | `speech` | 15회 | 짧은 문장 |
| 웃음 | `laugh` | 10회 | |
| 생활잡음 | `noise` | 15회 | 박수, 문 닫기, 의자 끌기, 키보드 |

기침 검출기가 이런 소리에 반응하면 그 뒤 식별 단계는 의미가 없습니다. 오탐 원인을 잡으려면 필요합니다.

## 5. 파일명 및 라벨링

스크립트가 자동으로 처리합니다. 수동으로 이름을 바꾸지 마세요.

```
{speaker}_{session}_{distance}_{type}_{index}.wav

예) s01_ses01_100cm_dry_007.wav
    x01_ses02_200cm_natural_003.wav
    neg_ses01_100cm_noise_012.wav
```

동시에 `~/cough_data/metadata.csv` 에 아래 정보가 자동 기록됩니다.

```
filename, speaker, session, distance_cm, type, index,
peak, rms, peak_ratio, duration_s, rate, recorded_at
```

`peak_ratio` 컬럼은 나중에 게인을 실측으로 정할 때 그대로 쓸 수 있습니다.

---

## 6. 오디오 포맷

| 항목 | 값 | 이유 |
|---|---|---|
| 샘플레이트 | 48000 Hz | I2S 오버레이 고정값 |
| 채널 | mono (왼쪽만) | `L/R`→GND 이므로 오른쪽은 항상 0 |
| 비트 | 32bit int (24bit 유효) | **원본 손실 없이 저장.** 게인·리샘플링은 학습 파이프라인에서 |
| 클립 길이 | 3초 | 기침 1회 + 여유 |

캡처 시점에 게인을 곱하거나 16bit로 줄이지 않는 것이 핵심입니다. 나중에 게인 값을 바꾸고 싶을 때 다시 녹음하지 않아도 됩니다.

ECAPA-TDNN 입력용 16kHz 변환은 Mac 쪽 학습 파이프라인에서 처리하세요. 48000 → 16000은 정확히 3:1이라 리샘플링이 깔끔합니다.

## 7. 품질 기준

스크립트가 자동으로 걸러냅니다.

| 판정 | 조건 | 처리 |
|---|---|---|
| `TOO_QUIET` | peak < full scale의 0.5% | 저장 안 함, 재녹음 |
| `CLIPPED` | peak > full scale의 90% | 저장 안 함, 재녹음 |
| `OK` | 그 사이 | 저장 |

세션이 끝나면 반드시 **몇 개를 무작위로 골라 직접 들어보세요.** 숫자상 `OK`여도 마이크가 옷에 쓸린 소리만 들어간 경우가 있습니다.

---

## 8. 실행 순서

파이에서:

```bash
# 화자 s01, 세션 1, 100cm, 마른기침 20회
python3 collect_cough.py --speaker s01 --session 1 --distance 100 --type dry --count 20

# 이어서 자연기침 10회
python3 collect_cough.py --speaker s01 --session 1 --distance 100 --type natural --count 10

# 거리 바꿔서
python3 collect_cough.py --speaker s01 --session 1 --distance 200 --type dry --count 10
```

세션 종료 후 Mac으로 회수:

```bash
scp -r mh@mh.local:~/cough_data ~/Downloads/
```

## 10. 주의사항

**개인정보**: 기침 소리와 음성은 개인 식별 정보입니다. 참여자에게 수집 목적·보관 기간·공개 범위를 미리 설명하고 동의를 받으세요. 대회 제출 시 원본 음성을 그대로 포함할지 여부도 미리 정해두는 게 좋습니다.

**건강**: 의도적 기침을 반복하면 목이 상합니다. 한 세션에서 한 사람이 60회를 몰아서 하지 말고, 중간에 물을 마시며 쉬게 하세요. 감기 등으로 실제 기침을 하는 팀원이 있다면 `natural` 샘플을 얻을 좋은 기회지만, 컨디션을 우선하세요.

**샘플 수가 부족할 때**: 3~4명 × 120개면 ECAPA-TDNN을 처음부터 학습시키기엔 턱없이 부족합니다. VoxCeleb 등으로 **사전학습된 ECAPA를 그대로 쓰고, 임베딩 추출 + 코사인 유사도 임계값** 방식으로 접근하세요. 이 방식은 화자당 10~20개 등록 샘플로도 동작합니다. 파인튜닝은 그다음 문제입니다.
